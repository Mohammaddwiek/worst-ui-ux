# worst-ui-ux

The OmniCorp Synergy Portal™: a sign-up page built to be as frustrating as possible. Plain HTML, CSS and JavaScript, with no build step and no backend.

## Run

Open `index.html` in a browser. Serving it locally (`npx serve .`) also works.

## Assets

- `video/video.mp4`: the prank video. It plays at the end of the progress bar and when you click "I Accept the Terms".
- `logo/logo.jpeg`: the club logo that falls with the confetti. If it's missing, `logo.png` and then the placeholder `logo.svg` in the root are used.

Both paths are set in `js/config.js`.

## Panic key

Press **Shift + Esc** to turn off the animations for demos.
